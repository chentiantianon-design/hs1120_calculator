PVT-10 · 12项指标自动计算器

逐试次反应时 → 有效/无效判定 → 12项PVT结果 → 一键导出CSV。所有计算均在当前浏览器本地完成。

① 输入数据

支持直接粘贴 Excel 的数据，或者导入CSV/TSV/TXT。输入格式A：每行一个RT（毫秒）。格式B：第一行表头 participant,rt_ms,event；event可不填。支持一次输入多个被试。建议同一被试不同测试批次使用不同编号（例如 PAT002_01、PAT002_02），避免被合并。

事件字段写法： valid正常、timeout超时、false_start提前反应、wrong_key错键、fail_release按键未释放、missing缺失。也识别常见中文名称。空event时，根据RT自动判断：RT<100视为False start，RT≥100且≤30000为有效RT；仅有空白RT不能推断超时。如记录了刺激前的错误启动，须在event列标记，不能仅靠RT数据推断。

③ 判定和计算规则

类别判定参与RT相关指标其他处理
有效普通反应100 ≤ RT < 500 ms是有效刺激数+1
Lapse500 ≤ RT ≤ 30000 ms是失效次数+1
Timeoutevent=timeout是，RT=30000 ms有效刺激数与Lapses各+1
False start无刺激时按键，或RT < 100 ms否False starts+1
Wrong keyevent=wrong_key否排除、质控计数
Fail-to-releaseevent=fail_release否排除、质控计数
Missing空RT且无事件；或event=missing否缺失记录，不当作超时

最快/最慢10%：先将所有有效RT从小到大排序，取 k = floor(0.1 × n + 0.5) 个试次（四舍五入）。93个有效试次取9个，97个取10个。若k=0，10%指标记NA。RT倒数统一为1000/RT (s⁻¹)；超时30,000 ms参与排序。四舍五入和边界相同RT时只取k个，为本研究编程约定，并非Basner & Dinges原文明示的取整法。
